# POS Frontend

React + TypeScript frontend for the Telecom Recharge Platform.

## Setup

```bash
npm install
npm run dev
```

Runs at `http://localhost:5173`.

## Environment

Configure via `.env` file or the gear icon in the UI:

| Variable | Description | Default |
|---|---|---|
| `VITE_API_BASE_URL` | Backend API URL | `http://localhost:5000/api` |
| `VITE_API_KEY` | API authentication key | (must be set) |
